﻿UI-001 — DIRECCIÓN VISUAL Y ESPECIFICACIÓN DE INTERFAZ
Taco Loco Foodtrack
CuyoConsulting and Development
Fecha: 08/08/2026
Estado: EN PROGRESO — Fase 4 UI


1. PROPÓSITO
Definir la dirección visual del MVP a partir de UX-001 y de la identidad real observada en los flyers de Taco Loco. Esta fase no redefine flujos ni reglas de negocio: transforma la UX cerrada en una interfaz clara, consistente, mobile-first y lista para implementación.


Fuentes canónicas:
• ALC-001 — Alcance funcional MVP.
• MEN-001 — Catálogo y modelo funcional del menú — CERRADO.
• UX-001 — Flujos críticos y arquitectura de experiencia — CERRADO.
• PRE-DEV-002 — Proceso profesional, roles y gate de construcción.
• Flyers aportados por Taco Loco como referencia visual y fotográfica.


2. OBJETIVO VISUAL
La interfaz debe conservar la energía visual mexicana de Taco Loco sin trasladar al celular la densidad gráfica del flyer. El producto digital debe sentirse inequívocamente Taco Loco, pero priorizar lectura, velocidad y jerarquía.


Concepto: “Taco Loco digital, no flyer reducido”.


Se conserva:
• fondo oscuro;
• verde, rojo y amarillo como acentos de marca;
• mascota/logo;
• fotografías apetitosas del producto;
• tono visual informal y enérgico;
• elementos gráficos mexicanos usados con moderación.


Se reduce:
• cantidad de tipografías decorativas;
• marcos y ornamentos simultáneos;
• textos superpuestos sobre fotografías;
• bloques densos de información;
• uso de color como único indicador de estado.


3. SISTEMA VISUAL MÍNIMO
No se crea un Design System corporativo completo. Se define un UI Kit suficiente para menú público y administración.


3.1 Paleta base propuesta
Los valores son tokens iniciales para diseño y podrán ajustarse mínimamente en Penpot por contraste y fidelidad visual.


• Brand/Background: #0E0E0D — fondo principal público.
• Brand/Surface: #181714 — tarjetas y superficies elevadas.
• Brand/Surface-2: #211F19 — superficies de énfasis.
• Brand/Cream: #F5E8C8 — texto principal cálido.
• Brand/Muted: #B9B09E — texto secundario.
• Brand/Green: #25833F — acento verde inspirado en el flyer.
• Brand/Red: #D5322C — acento rojo.
• Brand/Yellow: #F4B72B — acento amarillo.
• Brand/Border: #3B3529 — bordes discretos.
• State/Danger: #D94A40 — agotado/error.
• State/Success: #3B9B58 — disponible/confirmación.


Regla: verde/rojo/amarillo son acentos. El fondo no debe convertirse en un mosaico de colores; la legibilidad domina.


3.2 Tipografía
Propuesta para prototipo:
• Display/Marca y encabezados de categoría: Bebas Neue u Oswald, en mayúsculas o títulos breves.
• UI/Contenido: Inter o una sans serif equivalente de alta legibilidad.


No se replicarán fuentes decorativas del flyer en descripciones, precios, formularios ni navegación.


Escala móvil de referencia:
• Hero/Marca: 28–34 px según composición.
• Título de categoría: 24–28 px.
• Nombre de producto: 17–19 px / semibold.
• Precio: 18–20 px / bold.
• Descripción: 14–15 px / line-height amplio.
• Labels/estados: 12–13 px.


3.3 Espaciado y forma
Base de espaciado: múltiplos de 4 px.
Uso preferente: 8 / 12 / 16 / 24 / 32.


• Radio de tarjetas: 14–18 px.
• Chips de categoría: radio alto/pill.
• Botones principales: altura mínima 48 px.
• Objetivos táctiles: mínimo aproximado 44×44 px.
• Separación entre secciones: 28–36 px móvil.


4. MENÚ PÚBLICO — COMPOSICIÓN MOBILE-FIRST
Ancho de diseño de referencia: 390 px.


Orden visual:
1. Header compacto de marca.
2. Navegación de categorías sticky.
3. Destacados, solo cuando existan.
4. Secciones del catálogo.
5. Bloque informativo de salsas cuando corresponda.
6. CTA persistente “Pedir por WhatsApp”.


4.1 Header
Debe usar el logo/mascota como elemento reconocible, pero ocupar poco alto de pantalla.


Contenido:
• logo Taco Loco;
• frase “Sabor que te vuelve loco” como elemento secundario opcional;
• no usar pantalla splash ni hero gigante antes del menú.


Objetivo: marca visible en el primer viewport sin retrasar el acceso a categorías/productos.


4.2 Navegación de categorías
Formato: fila horizontal scrollable de chips.


Estados:
• normal;
• activo;
• focus;
• pressed.


La fila permanece accesible al hacer scroll. El chip activo puede usar amarillo/crema sobre fondo oscuro o verde con contraste suficiente. UI final debe evitar que siete categorías compitan simultáneamente con colores diferentes.


4.3 Destacados
Sección condicional. Si no hay productos featured, no aparece.


Tratamiento recomendado: una o dos tarjetas visualmente más fuertes al inicio, sin carrusel obligatorio.


No debe duplicar excesivamente contenido ni desplazar el catálogo demasiado hacia abajo.


4.4 Tarjeta de producto
Patrón principal recomendado: tarjeta horizontal compacta.


Estructura:
• bloque de contenido a la izquierda;
• imagen opcional a la derecha, aproximadamente 96–112 px;
• nombre;
• descripción corta/ingredientes;
• precio muy visible;
• estado agotado cuando corresponda;
• indicación de opción (“1 salsa a elección”, “carne a elección”) como metadata breve.


Ventaja: permite escanear varios productos rápidamente sin convertir el menú en una galería fotográfica.


Variantes:
A. Producto con imagen.
B. Producto sin imagen.
C. Producto destacado.
D. Producto agotado.


4.5 Estado agotado
Debe continuar visible.


Tratamiento:
• badge textual “Agotado”;
• imagen atenuada si existe;
• contraste del contenido reducido moderadamente, pero nombre/precio siguen legibles;
• no usar solamente rojo;
• no esconder la tarjeta.


4.6 Precios
Formato visual argentino: $ 10.000.
El precio es uno de los elementos de mayor contraste en cada tarjeta.


4.7 Salsas
Como MEN-001 las modela como modificadores, UI puede mostrar una sección informativa compacta:
“Salsas disponibles: Guacamole · Cheddar · Criolla · Picante · Roquefort”.


Puede apoyarse en fotografías recortadas del flyer, pero no necesita una tarjeta por salsa en el MVP.


5. CTA WHATSAPP
Decisión UI: barra/botón persistente inferior en móvil.


Contenido: icono + “Pedir por WhatsApp”.


Reglas:
• respeta safe-area inferior;
• no tapa precio ni contenido;
• permanece visible durante el scroll;
• contraste alto;
• tamaño táctil cómodo;
• puede usar verde asociado a acción, pero visualmente integrado con la marca.


En desktop puede convertirse en botón persistente discreto o CTA visible en lateral/header sin ocupar una barra completa.


6. USO DE IMÁGENES
Fuente primaria inicial: fotografías ya existentes en el flyer aportado.


Se identificaron recortes aprovechables para prototipo de:
• logo/mascota;
• tacos;
• pizza;
• nachos;
• quesadillas;
• gordita mexicana;
• salsas.


Criterios:
• evitar colocar foto en todos los productos solo para llenar espacio;
• no usar texto impreso del flyer dentro de la foto si puede recortarse;
• priorizar encuadres donde el alimento sea protagonista;
• usar relación de aspecto consistente en cada patrón de tarjeta;
• si un producto importante no tiene imagen útil, se podrá generar posteriormente una imagen coherente, pero nunca sustituir datos reales del producto.


7. ADMINISTRACIÓN — DIRECCIÓN VISUAL
El admin prioriza operación sobre marketing. No necesita replicar la estética intensa del menú público.


Dirección: interfaz limpia, neutra y de alta legibilidad, con acentos Taco Loco para marca y acciones principales.


Se propone tema claro o neutro como base operativa, con:
• fondo gris muy claro/crema;
• cards blancas;
• texto oscuro;
• verde como acción positiva/disponible;
• rojo para agotado/error;
• amarillo/brand como detalle de identidad.


7.1 Login
Composición simple:
• logo pequeño;
• título “Administración Taco Loco”;
• email/usuario;
• contraseña;
• CTA ingresar;
• error inline.


Sin ilustraciones pesadas ni marketing adicional.


7.2 Listado de productos
Mobile-first.


Cada fila/card debe mostrar:
• nombre;
• categoría;
• precio;
• miniatura opcional;
• toggle Disponible/Agotado;
• acción Editar.


En la parte superior:
• búsqueda simple;
• filtro categoría;
• “Nuevo producto”.


La disponibilidad se cambia sin abrir edición.


7.3 Edición de producto
Formulario de una columna en móvil.


Agrupación recomendada:
A. Información: nombre, descripción, categoría.
B. Precio.
C. Imagen.
D. Estado: publicado, disponible, destacado.
E. Opciones/modificadores.
F. Orden.


Acciones:
• Guardar como CTA primario.
• Cancelar/volver como secundaria.
• feedback persistente o toast accesible tras guardar.


8. RESPONSIVE
Móvil: una columna y navegación táctil.
Tablet: mayor ancho de tarjeta y posibles dos columnas en catálogo si la lectura se mantiene.
Desktop: contenido centrado con max-width; catálogo puede usar dos o tres columnas según densidad, manteniendo orden por categorías.


No se crearán comportamientos funcionales diferentes por dispositivo.

10. ESTADOS DE INTERACCIÓN
Todo componente interactivo debe contemplar:
• default;
• hover cuando aplique;
• pressed;
• focus visible;
• disabled;
• loading cuando aplique;
• error cuando aplique.


No se diseñará animación compleja. Transiciones breves y funcionales.


11. ACCESIBILIDAD VISUAL
• contraste de texto y controles suficiente;
• no depender solo de rojo/verde;
• focus visible;
• textos corporales no decorativos;
• precios legibles sin zoom;
• badges con texto;
• botones de al menos 44 px táctiles;
• imágenes con alternativa textual según función.

14. CRITERIO DE CIERRE DE FASE 4
UI-001 se marca CERRADO cuando:
• estén aprobados dirección visual y tokens;
• menú público mobile esté diseñado;
• estados clave estén visibles;
• login, listado y edición admin estén diseñados;
• exista UI Kit mínimo;
• se haya revisado contraste, legibilidad, responsive y consistencia;
• UX-001 pueda implementarse sin decisiones visuales estructurales pendientes.
