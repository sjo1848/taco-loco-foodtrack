## INICIO DEL PROMPT

### Objetivo

Crear el set completo de imágenes del menú digital de Taco Loco Foodtrack utilizando una herramienta de generación de imágenes.

Genera exactamente una imagen individual por producto. No hagas collages, mosaicos ni una sola imagen con todo el menú.

### Fuente canónica

La lista incluida aquí es la fuente de verdad. No agregues, reemplaces ni elimines ingredientes. No deduzcas recetas adicionales a partir del nombre comercial.

Si un producto no especifica ingredientes, sabor, marca o presentación, utiliza una representación visual neutra. Si no es posible hacerlo con fidelidad, no generes una versión engañosa: regístralo como `requiere referencia real`.

### Estilo visual del set

- Fotografía gastronómica profesional, realista y apetecible.
- Identidad mexicana contemporánea.
- Fondo carbón oscuro mate, aproximadamente `#171817`.
- Iluminación cálida lateral y contraste alto.
- Colores naturales, sin sobresaturación.
- Encuadre cercano en ángulo aproximado de 45 grados.
- Producto centrado y completamente visible.
- Profundidad de campo suave.
- Presentación abundante, artesanal y ordenada.
- Misma iluminación, fondo, escala y tratamiento en toda la colección.
- Formato cuadrado 1:1.
- Resolución mínima 1536 × 1536.
- Entrega en PNG o JPEG de alta calidad. La aplicación convertirá a WebP.
- Margen de seguridad alrededor del producto para recorte responsive.
- La imagen debe seguir siendo clara como miniatura de aproximadamente 104 × 104 px.

### Prohibiciones globales

No incluyas texto, nombres, precios, logotipos, marcas de agua, menús impresos, packaging inventado, personas, manos, cubiertos innecesarios, ingredientes no especificados, acompañamientos no indicados, papas fritas, bebidas junto a platos, fondos blancos, estilo cartoon, ilustración, render 3D, comida flotando, deformaciones ni decoración estereotipada.

No agregues cilantro, cebolla, jalapeños, limón, palta, crema, arroz, frijoles, guarniciones ni salsas si no están indicados explícitamente.

Las únicas salsas válidas son Guacamole, Cheddar, Criolla, Picante y Roquefort. Cuando diga `1 salsa a elección`, muestra solamente un recipiente separado con guacamole. Cuando diga `carne a elección`, muestra una sola carne cocida como representación neutra; no mezcles carnes.

### Control de calidad

Antes de aceptar cada imagen verifica:

1. Producto y categoría correctos.
2. Cantidad correcta cuando el nombre dice x2 o x4.
3. Solamente aparecen ingredientes permitidos.
4. No hay texto, precio, logo ni marca de agua.
5. No hay ingredientes decorativos inventados.
6. No hay manos, personas ni acompañamientos.
7. Fondo, iluminación y encuadre consistentes.
8. El producto funciona como miniatura cuadrada.
9. No se confundieron los dos productos llamados Taco Loco.
10. La imagen no promete una presentación distinta a la real.

### Entrega

Guarda las imágenes aprobadas en `assets/menu-source/` usando exactamente los nombres indicados.

Crea `assets/menu-source/manifest.md` con nombre, categoría, archivo, estado (`aprobado`, `provisional` o `requiere referencia real`), ingredientes visibles, decisiones, advertencias y modelo utilizado.

No sobrescribas archivos existentes sin conservar la versión anterior.

Al finalizar informa imágenes generadas, productos omitidos, referencias reales necesarias, ingredientes dudosos y diferencias respecto del catálogo.

No publiques, no subas a R2 y no modifiques la base de datos. La aprobación visual sucede antes de cargar las imágenes al sistema.
