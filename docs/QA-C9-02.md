# QA C9-02 — Flujo de pedido UX

Estado: completado localmente — 2026-08-09.

## Implementado

- Feedback accesible al agregar, editar, quitar y vaciar el pedido.
- Acción explícita para quitar una línea completa.
- Acción para vaciar el pedido desde el resumen.
- Límite de 20 unidades por línea también al repetir `Agregar`.
- Error visible cuando falta un modificador obligatorio.
- CTA contextual: enviar pedido cuando está abierto y consultar selección cuando está pausado.
- Persistencia vigente en `sessionStorage` conservada.
