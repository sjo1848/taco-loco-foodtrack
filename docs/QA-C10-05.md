# QA-C10-05 — WhatsApp adaptativo en móvil

Fecha: 2026-08-10

## Casos

- [ ] Móvil 360–390 px: agregar producto y tocar “Abrir WhatsApp”; verificar que no aparece pestaña en blanco.
- [ ] Móvil 360–390 px: verificar que `wa.me` recibe el número correcto y el mensaje prellenado.
- [ ] Móvil con WhatsApp instalado: verificar que el sistema abre la aplicación mediante `whatsapp://send`.
- [ ] Móvil sin WhatsApp instalado: verificar fallback a WhatsApp Web.
- [ ] Escritorio: verificar apertura en pestaña nueva y conservación del menú.
- [ ] Local cerrado o selección vacía: verificar consulta directa por WhatsApp.
- [ ] API de intención caída: verificar mensaje de error y que no se navega con un pedido no registrado.
