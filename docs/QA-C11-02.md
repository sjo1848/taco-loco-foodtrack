# QA-C11-02 — Bandeja de pedidos reactiva

Fecha: 2026-08-12

## Resultado

Implementación local aprobada técnicamente. La bandeja dejó de usar consultas periódicas y ahora recibe snapshots mediante SSE autenticado, con eventos originados en PostgreSQL después del commit de la transacción.

La prueba pública con el Quick Tunnel de Cloudflare no es válida para este criterio: `trycloudflare.com` no soporta SSE. El origen local sí entregó el evento; el borde del Quick Tunnel cerró/bloqueó el stream, por lo que el Admin público no podía reaccionar.

## Evidencia ejecutada

- Migración `20260812000000_add_order_event_sequence` aplicada sobre PostgreSQL local.
- `pnpm db:generate` aprobado.
- `pnpm lint` aprobado.
- `pnpm typecheck` aprobado.
- `pnpm test` aprobado: 28 tests.
- `pnpm build` aprobado.
- `GET /api/admin/orders/events` sin sesión devuelve `401`.
- Stream autenticado entrega eventos con `id` secuencial y snapshot serializable del pedido.
- Smoke del canal PostgreSQL → SSE ejecutado con `NOTIFY`; el evento fue recibido una sola vez por el stream.
- Prueba E2E local con dos pestañas: menú → creación de `TL-0032` → Admin recibió el pedido sin F5; el pedido de prueba fue eliminado después.
- Prueba E2E detrás del Quick Tunnel: el pedido `TL-0032` se creó correctamente y el mensaje de WhatsApp fue correcto, pero el stream recibió `ERR_CONNECTION_RESET`; la causa es la limitación documentada del Quick Tunnel, no la persistencia del pedido.

## Criterios verificados

- No hay `setInterval` ni polling en `OrdersBoard`.
- La bandeja hace upsert por `order.id`; una transición no duplica la fila.
- El cursor `OrderEvent.sequence` permite replay desde `Last-Event-ID` o `after`.
- El stream conserva reconexión automática de `EventSource` y muestra estado `En vivo` / `Reconectando…`.

## Pendiente de validación operativa

- Prueba física completa: menú público → WhatsApp → recepción en Admin → transición de estado.
- Verificación final detrás de un túnel Cloudflare nombrado/remotamente gestionado, no `trycloudflare.com`, y con reinicio controlado del proceso.
